PNEUMO-FLUOR TOOLKIT (PFT): ENVIRONMENT SETUP
================================================================================
Document version: 2026-08-02
Platform used for the tested commands: Windows 10/11, PowerShell, NVIDIA GPU

PFT uses isolated Python environments because the segmentation frameworks do not
share one fully compatible dependency stack.

Recommended environments:

1. pft
   Main toolkit environment.
   Includes Cellpose 3 through pyproject.toml.
   Used for CZI/OME-Zarr processing, filtering, deconvolution, statistics,
   Cellpose, and the standard project utilities.

2. pft_stardist
   Dedicated TensorFlow 2.10.1 and StarDist 0.9.2 environment.
   This separation protects the tested NumPy, TensorFlow, CSBDeep, Zarr, and
   scikit-image versions.

3. pft_omni
   Dedicated Omnipose 1.1.4 and CUDA-enabled PyTorch environment.
   This separation protects the cellpose_omni, AICSImageIO, Dask, Zarr, fsspec,
   urllib3, and CUDA NVRTC compatibility requirements.

Do not install all three framework stacks into one environment.

MAIN PFT ENVIRONMENT: CELLPOSE AND STANDARD PIPELINE

Cellpose is the primary instance-segmentation framework and is therefore a
normal dependency in pyproject.toml.

conda create --name pft python=3.10.12 --yes
conda activate pft

python -m pip install --upgrade pip setuptools wheel

conda install `
    pytorch=2.5.1 `
    torchvision=0.20.1 `
    pytorch-cuda=11.8 `
    -c pytorch `
    -c nvidia `
    --yes

Install the project in editable mode
Standard project plus Cellpose:

python -m pip install -e .
Add the TensorFlow U-Net stack:
python -m pip install -e ".[unet]"
Add BM3D and napari when required:
python -m pip install -e ".[bm3d,napari]"
Development tools:
python -m pip install -e ".[dev]"

Check the installation

python -m pip check
python scripts\check_project_imports.py

When Python is executed through its absolute path rather than conda activate,
the environment's bin directory must be added explicitly.

$OMNI_ENV = "C:\Users\ra18qyqu\.conda\envs\pft_omni"
$PY_OMNI = Join-Path $OMNI_ENV "python.exe"

$env:PATH = @(
    (Join-Path $OMNI_ENV "bin")
    (Join-Path $OMNI_ENV "Library\bin")
    (Join-Path $OMNI_ENV "Scripts")
    $OMNI_ENV
    $env:PATH
) -join ";"

$env:CUDA_PATH = $OMNI_ENV
$env:CUDA_PATH_V11_8 = $OMNI_ENV

Env used for
================================================================================
Use pft:
- CZI reading and OME-Zarr creation
- OME-Zarr validation
- filtering and deconvolution
- standard visualizations
- Cellpose training, inference, screening, and validation
- quantitative analysis, graphs, and statistics
- napari integration
- U-Net CPU execution or the locally configured TensorFlow runtime

Use pft_stardist:
- StarDist pretrained-model screening
- StarDist fine-tuning
- StarDist inference and validation
- TensorFlow GPU execution on native Windows

Use pft_omni:
- Omnipose pretrained-model screening
- Omnipose fine-tuning
- Omnipose inference and validation
